# valka-mravenist

Pod starou hrušní na konci zahrady žije několik mravenčích kolonií. Léto končí, potravy ubývá a každé mraveniště chce ovládnout co největší kus zahrady dřív, než přijde zima. Vaším úkolem je vytvořit tahovou strategickou hru, ve které proti sobě bojují dvě a více kolonií. Hráči se u počítače střídají, případně může za některou kolonii hrát počítač

## Sestavení

Projekt vyžaduje CMake 3.20 nebo novější a překladač s podporou C++20.

```sh
cmake -S . -B build
cmake --build build
./build/valka_mravenist
```

Spustitelný soubor bude v adresáři `build`.
